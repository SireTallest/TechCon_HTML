# **TechCon 2024 Website: Connecting Innovators** 🌐

This project delivers the official static website for TechCon 2024, a premier technology conference. Designed to be a central hub for attendees and prospective participants, the site provides essential information regarding the event's schedule, registration process, historical context, and contact details. It serves as an informative and engaging platform, capturing the essence of innovation and community that TechCon represents.

## Installation 🚀

To get a local copy of this project up and running, follow these simple steps.

### Clone the Repository

First, clone the repository to your local machine:

```bash
git clone https://github.com/SireTallest/TechCon_HTML.git
```

### Setup Instructions

1.  📂 Navigate into the project directory:
    ```bash
    cd TechCon_HTML/techcon_website
    ```
2.  🖥️ Open any of the `.html` files (e.g., `index.html`, `about.html`) directly in your web browser. You can typically do this by double-clicking the file.

That's it! The website is entirely client-side and requires no server configuration.

## Usage 🧑‍💻

Once the project is open in your browser, you can navigate through the different sections of the TechCon 2024 website using the navigation bar located at the top of each page.

*   **Home (`index.html`)**: Get an overview of TechCon 2024.
*   **About (`about.html`)**: Learn about the conference's history, mission, and past speakers.
*   **Schedule (`schedule.html`)**: View the detailed agenda of sessions, debates, and networking events.
*   **Register (`register.html`)**: Sign up for the conference using the event registration form.
*   **Contact (`contact.html`)**: Find contact information and a form to get in touch with the TechCon team, along with venue details and a map.

## Features ✨

*   **Comprehensive Event Information**: Provides a clear introduction to TechCon 2024, highlighting its purpose and significance.
*   **Detailed Schedule**: An organized table format displays session times, topics, and speakers for easy planning.
*   **Event Registration Form**: A user-friendly form allows attendees to register for the conference, including name, email, and password creation.
*   **Interactive Contact Form**: Facilitates communication with the TechCon team, complete with social media links and venue details with an embedded map.
*   **Historical Overview and Mission**: Dedicated sections on the "About" page share the conference's journey, achievements, and core values.
*   **Responsive Navigation**: Easy-to-use navigation links ensure seamless transitions between different sections of the website.
